# Virexo Digital Business Website – Homepage

A responsive homepage for Virexo, a fictional digital studio that turns ambitious ideas into clear, high-performing digital experiences.

## Highlights

- Responsive navigation with mobile menu
- Editorial hero with clear calls to action
- Studio/about story, services, process, selected work, contact form, and footer
- Scroll-reveal motion, hover states, marquee detail, and reduced-motion support
- Working contact form success state
- Accessible labels and semantic anchor navigation

## Run locally

Requires Node.js 18+ and npm or pnpm.

    npm install
    npm run dev

Then open the local URL printed by Vite.

## Project structure

- `src/App.tsx` — homepage content, interactions, and routing
- `src/index.css` — visual system, responsive layout, and motion
- `src/components` — reusable UI primitives
- `public` — favicon and crawler metadata
